## 1. Pipeline Overview

The target pipeline consists of nine steps:

1. Load `google/medgemma-4b-it` from Hugging Face.  
2. Preprocess ODIR-5K fundus images to 896×896 and normalize to [-1, 1].  
3. Run a forward pass with `output_hidden_states=True`.  
4. Extract vision tokens (first 256 positions) and text tokens (remaining positions) from the decoder hidden states.  
5. Compute mean-pooled representations and apply softmax to get distributions.  
6. Compute KL divergence between the vision and text distributions.  
7. Save results (image ID, KL divergence, predicted answer, ground truth) to CSV.  
8. Statistical analysis: t-test (correct vs incorrect KL) and AUPRC using KL as the uncertainty score.  
9. Visualization: boxplot of KL for correct vs incorrect and a Precision–Recall curve.

## 3. Hidden-State Extraction from Decoder

**Claim**: MedGemma is based on Gemma 3, which uses a SigLIP vision encoder. An 896×896 image is split into 14×14 patches, then pooled into **256 soft image tokens** before being appended to the text sequence. The decoder is a 34-layer transformer with bidirectional attention on image tokens and interleaved local/global attention on text tokens [^2].  
**Source**: Gemma 3 Technical Report  
**URL**: https://arxiv.org/html/2503.19786v1  
**Date**: 2025-01-29

**Extraction during generation** [^3]:  
```python
with torch.no_grad():
    outputs = model.generate(
        **inputs, max_new_tokens=10,
        output_hidden_states=True,
        return_dict_in_generate=True, do_sample=False
    )
# Prefill hidden states (first element) contains full vision+text sequence
prefill = outputs.hidden_states[0]          # tuple of layers
last_layer = prefill[-1]                    # (batch, seq_len, hidden_dim)
vision_tokens = last_layer[:, :256, :]      # 256 SigLIP pooled tokens
text_tokens   = last_layer[:, 256:, :]      # prompt tokens
```

**Hook-based extraction** (alternative pattern):  
```python
hidden_cache = []
def hook_fn(module, inp, out):
    hidden_cache.append(out.detach().cpu())
handle = model.model.layers[-1].register_forward_hook(hook_fn)
_ = model.generate(**inputs, max_new_tokens=1)
handle.remove()
```

## 4. KL Divergence Computation in PyTorch

**Claim**: PyTorch's `F.kl_div` expects the **input** in log-probability space and the **target** as raw probabilities. Use `reduction='batchmean'` for the mathematically correct batch average.  
**Source**: GeeksforGeeks [^4]  
**URL**: https://www.geeksforgeeks.org/deep-learning/understanding-kl-divergence-in-pytorch/  
**Date**: 2025-11-08

```python
import torch.nn.functional as F

vision_dist = F.softmax(vision_mean, dim=-1)      # target (batch, hidden_dim)
text_log    = F.log_softmax(text_mean, dim=-1)   # input  (batch, hidden_dim)

kl = F.kl_div(text_log, vision_dist, reduction='batchmean')
```

**Manual vectorized form** (for custom epsilon control):  
```python
eps = 1e-10
kl_manual = (vision_dist * (vision_dist / (text_dist + eps)).log()).sum(dim=-1).mean()
```

## 5. ODIR-5K Data Loading Code

**Claim**: ODIR-5K contains ~10,000 fundus images with 8 multi-label categories. A custom PyTorch `Dataset` reading a pandas DataFrame is the standard pattern.  
**Source**: GitHub – JosueVP17 [^5]  
**URL**: https://github.com/JosueVP17/transfer-learning-ocular-disease  
**Date**: 2026-03-23

```python
import os, pandas as pd
from PIL import Image
from torch.utils.data import Dataset
import torch

class ODIRDataset(Dataset):
    def __init__(self, csv_path, img_dir, transform=None):
        self.df = pd.read_csv(csv_path)
        self.img_dir = img_dir
        self.transform = transform
    def __len__(self): return len(self.df)
    def __getitem__(self, idx):
        row = self.df.iloc[idx]
        img = Image.open(os.path.join(self.img_dir, row['filename'])).convert('RGB')
        label = row[['N','D','G','C','A','H','M','O']].values.astype(float)
        if self.transform: img = self.transform(img)
        return img, torch.tensor(label, dtype=torch.float)

# Binary glaucoma filter
df = pd.read_excel("odir5k/data.xlsx")
df['binary_label'] = df['G'].apply(lambda x: 1 if x == 1 else 0)
```

## 6. Medical Image Preprocessing (Fundus)

**Claim**: Standard fundus preprocessing includes black-border cropping, circular masking, CLAHE on the green channel, and resizing to 896×896.  
**Source**: CSDN Blog (youcans) [^6]  
**URL**: https://blog.csdn.net/youcans/article/details/158316317  
**Date**: 2026-02-23

```python
import cv2, numpy as np
from PIL import Image

def fundus_preprocess(img_pil, out_size=896, clahe_clip=2.2, grid=(8,8)):
    img = np.array(img_pil)
    bgr = cv2.cvtColor(img, cv2.COLOR_RGB2BGR)
    gray = cv2.cvtColor(bgr, cv2.COLOR_BGR2GRAY)
    mask = (gray > 10).astype(np.uint8) * 255
    ys, xs = np.where(mask > 0)
    crop = bgr[ys.min():ys.max()+1, xs.min():xs.max()+1] if len(xs) else bgr
    h, w = crop.shape[:2]
    side = min(h, w)
    y1, x1 = (h - side)//2, (w - side)//2
    square = crop[y1:y1+side, x1:x1+side]
    cm = np.zeros((side, side), np.uint8)
    cv2.circle(cm, (side//2, side//2), side//2, 255, -1)
    square[cm == 0] = 0
    b, g, r = cv2.split(square)
    g2 = cv2.createCLAHE(clahe_clip, grid).apply(g)
    rgb = cv2.cvtColor(cv2.merge([b, g2, r]), cv2.COLOR_BGR2RGB)
    return Image.fromarray(cv2.resize(rgb, (out_size, out_size), cv2.INTER_AREA))
```

## 7. AUPRC and Brier Score Computation

**Claim**: `average_precision_score` computes AUPRC directly from continuous scores; `brier_score_loss` measures calibration.  
**Source**: scikit-learn + Machine Learning Mastery [^7]

```python

# Negative KL is used as confidence (higher = more certain/correct)

precision, recall, _ = precision_recall_curve(y_correct, confidence_scores)
pr_auc = auc(recall, precision)
```

## 10. Statistical Testing: t-test and Mann–Whitney U

**Claim**: KL divergence distributions are often right-skewed. Run Shapiro–Wilk first; if non-normal, use Mann–Whitney U with effect size r.  
**Source**: Plotivy / SciPy docs [^10]  
**URL**: https://plotivy.app/techniques/mann-whitney-u-test

```python
from scipy import stats
import numpy as np

_, pc = stats.shapiro(kl_correct)
_, pi = stats.shapiro(kl_incorrect)
if pc > 0.05 and pi > 0.05:
    t, p = stats.ttest_ind(kl_correct, kl_incorrect, alternative='two-sided')
    print(f"t-test: t={t:.3f}, p={p:.4f}")
else:
    u, p = stats.mannwhitneyu(kl_correct, kl_incorrect, alternative='two-sided', method='exact')
    N = len(kl_correct) + len(kl_incorrect)
    mean_u = len(kl_correct) * len(kl_incorrect) / 2
    std_u = np.sqrt(len(kl_correct) * len(kl_incorrect) * (N + 1) / 12)
    r = ((u - mean_u) / std_u) / np.sqrt(N)
    print(f"Mann-Whitney U: U={u:.1f}, p={p:.4f}, r={r:.3f}")
```

## 12. Synthesized End-to-End Pipeline Snippet

```python
import torch, torch.nn.functional as F
from transformers import AutoProcessor, AutoModelForImageTextToText
from PIL import Image
import pandas as pd, numpy as np
from scipy import stats
from sklearn.metrics import average_precision_score, precision_recall_curve, auc
import seaborn as sns, matplotlib.pyplot as plt

model_id = "google/medgemma-4b-it"
model = AutoModelForImageTextToText.from_pretrained(model_id, torch_dtype=torch.bfloat16, device_map="auto")
processor = AutoProcessor.from_pretrained(model_id)

image = Image.open("odir5k/Training Images/0_right.jpg").convert("RGB")
prompt = "Does this fundus image show glaucoma? Answer yes or no."
messages = [
    {"role": "system", "content": [{"type": "text", "text": "You are an expert ophthalmologist."}]},
    {"role": "user", "content": [{"type": "text", "text": prompt}, {"type": "image", "image": image}]}
]
inputs = processor.apply_chat_template(messages, add_generation_prompt=True, tokenize=True,
                                       return_dict=True, return_tensors="pt").to(model.device, dtype=torch.bfloat16)

with torch.no_grad():
    outputs = model.generate(**inputs, max_new_tokens=5, output_hidden_states=True,
                             return_dict_in_generate=True, do_sample=False)

prefill = outputs.hidden_states[0]
last_layer = prefill[-1]
vision_repr = last_layer[:, :256, :]
text_repr   = last_layer[:, 256:, :]

vision_mean = vision_repr.mean(dim=1)
text_mean   = text_repr.mean(dim=1)
vision_dist = F.softmax(vision_mean, dim=-1)
text_dist   = F.softmax(text_mean, dim=-1)
kl = F.kl_div(text_dist.log(), vision_dist, reduction='batchmean')

input_len = inputs["input_ids"].shape[-1]
answer = processor.decode(outputs.sequences[0][input_len:], skip_special_tokens=True).strip().lower()

pd.DataFrame([{"image_id": "0_right", "kl_divergence": round(kl.item(), 6),
               "predicted_answer": answer, "ground_truth": "yes"}]).to_csv("bip_results.csv", index=False, mode='a', header=False)
```
